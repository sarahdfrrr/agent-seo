## Comment remplir ce fichier

**Avec GSC :**
```
Récupère les données Google Search Console de [mon-site.com]
et remplis ce template channels-seo.md avec toutes les pages
qui reçoivent du trafic organique.
```

**Sans GSC (manuellement) :**
```
Voici la liste de mes articles de blog :
[coller les URLs ou faire un sitemap]

Crée l'inventaire dans ce template.
Pour les positions et clics, laisse vide — on complétera avec Ahrefs.
```
